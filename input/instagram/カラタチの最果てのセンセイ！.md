# カラタチの最果てのセンセイ！

---

## 覚えたいセリフや表現

1. オタクは推しの**言葉を全部都合のいいように自分の中で翻訳して意訳して**、
   **盛に盛りまくって**生きているわけ

2. ちょっと感動しただけで、ｘで号泣した**とか書くしね**

3. 一回YouTubeで号泣って検索してください、
   **野々村議員が出てきます**、あれが号泣です

4. 関係ねぇだろ、あの号泣はちょっと別ラインの奴は俺は思うんだよな
   お前日向坂のMVを見ながら、**野々村議員みたいに「あ”あ”あ”あ”、日向最高」って泣いたのか？**
   お前それ**オタクの野々村議員をやってるだけだろ**
   **涙一粒も落ちませんとかではないんだ**

## 👆表現の考察

1. 「盛に盛った」とか、「都合のいいように」とかの、オタクへの表現がすごい

2. 「ちょっと…だけで書くし」で、書いた人への皮肉っぽさが好き

3. 野々村議員の号泣を例えに出すと、急に極端すぎて面白すぎ

4. 「泣いたのか」ってストレートに聞くのが好き
   オタクの野々村議員っていう例えがツッコミとして最高
   「とかではないんだ」＝「とかじゃないんだ」（んだって言い切って突き放し感を出すのがうまい）
