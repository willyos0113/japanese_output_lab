# japanese_output_lab

個人的日文「アウトプット（輸出）」訓練筆記庫。

素材來自日劇台詞、日本綜藝節目，以及有人在講故事的內容（劇情介紹、評論、考察、實況）——不是教科書例句，是真人真的會講的話。目標不是加強「読む・聞く」的理解力，而是加強「話す・書く」的輸出力：不只是看懂一句話，而是能在對的情境下，自己自然地講出來。

目前的重點場合：用日文講遊戲、動畫、日劇的故事（あらすじ、感想、考察、ネタバレ管理）。

## 這個庫在幹嘛

1. **收集**：把有感覺的台詞或講法連同完整情境記下來，關鍵表達標粗體。
2. **練習**：搭配 [Claude Code](https://claude.com/claude-code) 使用，讓 AI 扮演一個 30 歲上下的日本人，針對筆記內容出題、要我造句或講故事，並針對「自然度」（不只是文法對不對）給回饋。
3. **複習**：AI 讀 `review-log.md`，優先挑從沒考過、答錯過、最久沒複習的表達來考我，避免練完新的就忘了舊的。
4. **修正**：我自己寫的日文請 AI 改，反覆出現的錯誤類型記進 `mistakes.md`，慢慢看出自己的 pattern。

實際的 AI 互動規則寫在 [`CLAUDE.md`](./CLAUDE.md)（唯一規則來源，`AGENTS.md` 只指向它）。

## 筆記怎麼記

用 [Obsidian](https://obsidian.md/) 管理。

- **`drama/`**：一部劇/節目一個 Markdown 檔，同一部作品依集數用二級標題分段（`## ep1`、`## ep11`，小寫、不補零）。
- **`narration/`**：講故事的語言（介紹、評論、考察、實況等），由我自己蒐集整理，預設依功能分二級標題。
- 每則筆記用 `-` 條列一段**完整對話或完整一段話**（不是單獨抄一個詞），場景說明用括號註記。
- 值得學的重點表達用 **粗體** 標起來。

範例（`drama/さよならノワール.md` 的 `## ep11` 段落）：

```markdown
- 決着をつけたいと言ってたのに**腰砕けですね**
  **いいたい放題だね**
  いいたくなりますよ、逃げる黒木さんをみたくないんで
- 署長から勝手に動くなと改めて厳命された
  **くさいものには蓋をする**ってやつですか
```

保留完整對話而不是單記一個成語，是為了複習時能看出「這句話是在什麼情境下講出來的」。

## 檔案結構

```
.
├── CLAUDE.md          # AI 指示檔（唯一規則來源）
├── AGENTS.md          # 指向 CLAUDE.md
├── README.md          # 這份文件
├── review-log.md      # 複習紀錄
├── mistakes.md        # 錯誤日誌
├── drama/             # 日劇、綜藝的台詞筆記
│   └── <作品名>.md
└── narration/         # 講故事的語言（自行建立）
    └── <檔名>.md
```

## 使用方式

1. 在專案根目錄開 Claude Code。
2. 貼上想記的台詞或講法，請它幫忙整理成筆記格式並解釋語感。
3. 想練習時直接說「幫我造句練習」、「來練 1 分鐘あらすじ」或「複習」，AI 會依 `CLAUDE.md` 裡的規則出題。
4. 想被改日文時，直接貼上自己寫的內容，AI 會回饋並更新 `mistakes.md`。
