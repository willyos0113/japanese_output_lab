# kotoba_farm

個人的日文「アウトプット（輸出）」訓練筆記庫。聽到的「言葉」記下來、種下去，反覆複習、實際用出來，養成自己講得出口的日文——所以叫 kotoba farm（言葉の畑）。

素材來自日劇台詞、日本綜藝節目、動畫台詞，以及有人在講故事的內容（劇情介紹、評論、考察、實況）——不是教科書例句，是真人真的會講的話。目標不是加強「読む・聞く」的理解力，而是加強「話す・書く」的輸出力：不只是看懂一句話，而是能在對的情境下，自己自然地講出來。

目前的重點場合：用日文講遊戲、動畫、日劇的故事（あらすじ、感想、考察、ネタバレ管理）。

## 運作方式

一個「把聽到的日文，變成自己講得出來的日文」的循環（輸入＝播種，複習＝照顧，輸出＝收成）。每天做兩件事：**輸入**（看、聽、記）和**輸出**（寫、發）。筆記庫是**資料層**，Claude Code 是**教練層**，兩邊靠 [`AGENTS.md`](./AGENTS.md) 的規則接起來。

```
【輸入】看 drama／anime（也包含 youtube／instagram／日文課）
   │ 聽寫出不懂、不太會用的句子，標粗體
   │ 貼給 Claude：標出處・情境・nuance・語域，解釋為什麼這樣講
   ▼
筆記庫（drama / anime / youtube / instagram / 2idiots）
   │ 粗體表達 = 題庫
   │
   ├─▶ input/patterns.md
   │     助詞粗體、可抽成型的句子另外整理
   │
   ├─▶【複習】說「複習」，Claude 出題、回饋
   │     挑題：沒考過 > × 或 △ > 最久沒複習的 ○
   │     └─▶ review/review-log.md（○／△／×，決定下次挑題）
   │
   └─▶【輸出】寫 posts：日文遊記、分享文章等等
         企画 → 文案 → 平台成品，貼給 Claude 添削
         └─▶ review/mistakes.md（錯誤類型與累計次數）

review/mistakes.md 累積後，Claude 會點出個人 pattern，回頭影響之後的複習與輸出。
```

複習和輸出是兩件平行的事，都從筆記庫取材：複習檢查「記不記得」，輸出練習「用不用得出來」，彼此沒有先後順序。兩邊靠「複習」和「用出來」接起來：輸入累積的表達，要在輸出的 posts 裡實際用過，才算真的學會。

### 資料怎麼流動

| 檔案                 | 誰寫              | 誰讀                 | 作用                       |
| -------------------- | ----------------- | -------------------- | -------------------------- |
| 各素材資料夾的 `.md` | 我貼、Claude 整理 | 複習時 Claude 讀     | 題庫（粗體表達）           |
| `review/review-log.md` | Claude 複習後追加 | 下次複習挑題時       | 記憶曲線：誰沒考過、誰錯過 |
| `review/mistakes.md`   | Claude 改句後追加 | 點出個人 pattern 時  | 我的弱點清單               |
| `input/patterns.md`    | Claude 講解後整理 | 造句、講故事時回頭查 | 可重複使用的文型與助詞對照 |
| `output/posts/`        | 我寫、Claude 添削 | 不進題庫             | 實戰輸出                   |

實際的 AI 互動規則寫在 [`AGENTS.md`](./AGENTS.md)（唯一規則來源，`CLAUDE.md` 只匯入它）。

## 使用方式

先在專案根目錄開 Claude Code（`CLAUDE.md` 會匯入 `AGENTS.md`，Claude 才會知道角色設定和所有規則）。之後依當天要做的事，直接用一句話開口就行。

### 輸入：記新的表達

1. 看 drama、anime 時，聽寫出不懂或不太會用的句子，連同**完整的一段話**（不是單獨一個詞）記進 `input/` 對應的檔案，值得學的表達標**粗體**。
2. 把那一段貼給 Claude，說「幫我整理」或「這句特別在哪？」。它會講出處與情境、言外之意、語域，以及這句我能不能直接拿來用。
3. 如果粗體只框住一個助詞，它會以「為什麼這裡用這個助詞」來講；能抽成型的，請它整理進 `input/patterns.md`。

### 複習：說「複習」

說「複習」或「來複習」，Claude 會讀所有筆記的粗體表達當題庫，再讀 `review/review-log.md`，依「從沒考過 > 最後是 × 或 △ > 最久沒複習的 ○」挑題，混合不同作品。出題不照抄原句；回答後它給自然度回饋，並把每題結果追加到 `review/review-log.md`，你不用自己記。

### 輸出：寫 posts 並請 Claude 添削

1. 在 `output/posts/` 開新主題資料夾（`YYYYMMDD_english-slug`），先寫 `plan.md` 企画，再寫成品（`discord.md`、`copy.md` 等），照片放 `photos/`。格式規則在 `output/posts/.claude/skills/posts-format/SKILL.md`，編輯 posts 時 Claude 會照這份做。
2. 把自己寫的日文貼給 Claude，說「幫我改」。它針對「自然度」回饋，不只是文法對不對：文法正確但日本人不會這樣講的，會指出為什麼不自然，每個地方給 2–3 個替代說法。
3. 有 pattern 價值的錯誤（助詞、語域混用、直譯腔、自他動詞等）會自動記進 `review/mistakes.md`，同類型累加次數；累積到一定量，Claude 會主動指出你個人的弱點。想主動看的話，說「看一下我的 mistakes」就行。

### 口說式的輸出練習（想練再做）

不寫 posts 時，也可以請 Claude 扮演 30 歲上下的日本朋友直接開練：

- 「來練 1 分鐘あらすじ」：挑一部看過的作品，用日文講劇情，Claude 以日本朋友的角度回饋。
- 「三種版本」：同一部作品，分別講「ネタバレなし紹介」、「跟朋友聊（タメ口）」、「跟同事簡短報告（丁寧語）」。
- 「出情境給我」：Claude 只給情境、不給原句，你先用自己的話講，再跟原句比較。

## 筆記格式

用 [Obsidian](https://obsidian.md/) 管理。

- **`input/drama/`**：一部劇/節目一個 Markdown 檔（檔名帶年季，如 `2026夏_さよならノワール.md`），同一部作品依集數用二級標題分段（`## ep1`、`## ep11`，小寫、不補零）。
- **`input/anime/`**：一部動畫一個 Markdown 檔，格式同 `input/drama/`。
- **`input/youtube/`**：一個頻道一個 Markdown 檔，一支影片一個二級標題（`## 日期 | 影片標題`）。除了影片裡講的話，也可以記影片標題和觀眾留言（用 `（タイトル）`、`（コメント欄）` 標明來源）；整句粗體的留言是為了學「日本人在想什麼、聊什麼」，複習時考視角和前提。
- **`input/instagram/`**：一個帳號或一個節目一個 Markdown 檔，一則貼文一個二級標題（`## 日期 | 標題`，限時動態用 `## ストーリー`）。SNS 的口語和網路用語很多，要分清楚哪些是日常也能用、哪些只適合 SNS。`dm.md` 是別人的私訊，只放本機，見[注意事項](#注意事項)。
- **`input/2idiots/`**：日文課的筆記（上課筆記、老師的貼文、我自己寫的稿），結構自行決定。
- 每則筆記用 `-` 條列一段**完整對話或完整一段話**（不是單獨抄一個詞），場景說明用括號註記。
- 值得學的重點表達用 **粗體** 標起來。

範例（`input/drama/2026夏_さよならノワール.md` 的 `## ep11` 段落）：

```markdown
- 決着をつけたいと言ってたのに**腰砕けですね**
  **いいたい放題だね**
  いいたくなりますよ、逃げる黒木さんをみたくないんで
- 署長から勝手に動くなと改めて厳命された
  **くさいものには蓋をする**ってやつですか
```

保留完整對話而不是單記一個成語，是為了複習時能看出「這句話是在什麼情境下講出來的」。

## 檔案結構

```
.
├── AGENTS.md          # AI 指示檔（唯一規則來源）
├── CLAUDE.md          # 匯入 AGENTS.md（給 Claude Code 用）
├── README.md          # 這份文件
├── emoji.md           # 表情符號複製用的參考連結
├── input/             # 輸入：看 drama／anime 等記下來的素材
│   ├── drama/         # 日劇、綜藝的台詞筆記
│   │   └── <年季>_<作品名>.md   # 例：2026夏_さよならノワール.md
│   ├── anime/         # 動畫的台詞筆記
│   │   └── <作品名>.md
│   ├── youtube/       # YouTube 頻道的筆記
│   │   └── <頻道名>.md
│   ├── instagram/     # Instagram 帳號／節目的貼文筆記
│   │   └── <帳號或節目名>.md
│   ├── 2idiots/       # 日文課的筆記
│   │   └── <檔名>.md
│   └── patterns.md    # 從輸入素材萃取出的文型與助詞講解（不當題庫）
├── output/            # 輸出：我自己寫、發出去的東西
│   ├── posts/         # 我發出去的貼文（企画、文案、照片）
│   │   └── YYYYMMDD_主題/
│   └── slides/        # 預留給之後可能做的簡報（目前是空的）
└── review/            # 複習與回饋：AI 追加的紀錄
    ├── review-log.md  # 複習紀錄
    └── mistakes.md    # 錯誤日誌
```

## 注意事項

- `input/instagram/dm.md` 是別人的私訊，只放本機（已在 `.gitignore`），不會被當題庫，也不要 commit。
- `output/` 底下的內容是我發出去的成品，不進題庫。
