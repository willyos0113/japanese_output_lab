# japanese_output_lab

個人的日文「アウトプット（輸出）」訓練筆記庫。

素材來自日劇台詞、日本綜藝節目裡聽到、記下來的用詞和句子——不是教科書例句，是真人真的會講的話。目標不是加強「読む・聞く」的理解力，而是加強「話す・書く」的輸出力：不只是看懂一句話，而是能在對的情境下，自己自然地講出來。

## 這個庫在幹嘛

1. **收集** — 追劇/看節目時，把有感覺的台詞連同對話情境記下來，關鍵表達標粗體。
2. **練習** — 搭配 [Claude Code](https://claude.com/claude-code) 使用，讓 AI 扮演一個 30 歲上下的日本人，針對筆記內容出題、要我造句，並針對「自然度」（不只是文法對不對）給回饋。
3. **複習** — 請 AI 動態從舊筆記裡挑久沒複習到的表達來考我，避免練完新的就忘了舊的。

實際的 AI 互動規則寫在 [`CLAUDE.md`](./CLAUDE.md)。

## 筆記怎麼記

用 [Obsidian](https://obsidian.md/) 管理，規則很單純：

- 一部劇/節目一個資料夾
- 資料夾底下按集數拆檔案（`ep11.md`）
- 每則筆記用 `-` 條列一段**完整對話情境**（不是單獨抄一個詞），場景說明用括號註記
- 情境裡值得學的重點表達用 **粗體** 標起來

範例（`さよならノワール/ep11.md`）：

```markdown
- 決着をつけたいと言ってたのに**腰砕けですね**
  **いいたい放題だね**
  いいたくなりますよ、逃げる黒木さんをみたくないんで
- 署長から勝手に動くなと改めて厳命された
  **くさいものには蓋をする**ってやつですか
```

保留完整對話而不是單記一個成語，是為了複習時能看出「這句話是在什麼情境下講出來的」。

## 資料夾結構

```
.
├── CLAUDE.md              # AI 互動規則（角色設定、任務、複習機制）
├── README.md              # 這份文件
├── <劇名 / 節目名>/
│   ├── ep01.md
│   ├── ep02.md
│   └── ...
└── ...
```

## 使用方式

1. 在專案根目錄開 Claude Code。
2. 貼上想記的台詞，請它幫忙整理成筆記格式並解釋語感。
3. 想練習時直接說「幫我造句練習」或「複習」，AI 會依 `CLAUDE.md` 裡的規則出題。
