# japanese_output_lab

個人的日文「アウトプット（輸出）」訓練筆記庫。

素材來自日劇台詞、日本綜藝節目、動畫台詞，以及有人在講故事的內容（劇情介紹、評論、考察、實況）——不是教科書例句，是真人真的會講的話。目標不是加強「読む・聞く」的理解力，而是加強「話す・書く」的輸出力：不只是看懂一句話，而是能在對的情境下，自己自然地講出來。

目前的重點場合：用日文講遊戲、動畫、日劇的故事（あらすじ、感想、考察、ネタバレ管理）。

## 這個庫在幹嘛

一個「把聽到的日文，變成自己講得出來的日文」的循環。每天做兩件事：**輸入**（看、聽、記）和**輸出**（寫、發）。筆記庫是**資料層**，Claude Code 是**教練層**，兩邊靠 [`AGENTS.md`](./AGENTS.md) 的規則接起來。

### 運作 flow

```
【輸入】看 drama／anime（也包含 youtube／instagram／日文課）
   │ 聽寫出不懂、不太會用的句子，標粗體
   │ 貼給 Claude：標出處・情境・nuance・語域，解釋為什麼這樣講
   ▼
筆記庫（drama / anime / youtube / instagram / 2idiots）
   │ 粗體表達 = 題庫
   │
   ├─▶ input/patterns.md
   │     助詞粗體、可抽成型的句子另外整理
   │
   ├─▶【複習】說「複習」，Claude 出題、回饋
   │     挑題：沒考過 > × 或 △ > 最久沒複習的 ○
   │     └─▶ review/review-log.md（○／△／×，決定下次挑題）
   │
   └─▶【輸出】寫 posts：日文遊記、分享文章等等
         企画 → 文案 → 平台成品，貼給 Claude 添削
         └─▶ review/mistakes.md（錯誤類型與累計次數）

review/mistakes.md 累積後，Claude 會點出個人 pattern，回頭影響之後的複習與輸出。
```

複習和輸出是兩件平行的事，都從筆記庫取材：複習檢查「記不記得」，輸出練習「用不用得出來」，彼此沒有先後順序。

### 每天的兩條線

**輸入線**

1. 看 drama、anime，聽寫出不懂或不太會用的句子，連同**完整的一段話**（不是單獨一個詞）記進對應資料夾，值得學的表達標**粗體**。
2. 貼給 Claude 整理：出處、情境、意思與言外之意、語域、我能不能直接拿來用。助詞粗體會以「為什麼這裡用這個助詞」來講解，可抽成型的句子另外整理進 `input/patterns.md`。
3. 說「複習」時，Claude 讀所有筆記的粗體表達當題庫，再讀 `review/review-log.md`，依「從沒考過 > 最後是 × 或 △ > 最久沒複習的 ○」挑題，混合不同作品。出題不照抄原句；結束後把每題結果追加回 `review/review-log.md`。

**輸出線**

1. 寫 `output/posts/`：日文遊記、分享文章等等。一個主題一個資料夾（`plan.md` 企画 → `copy.md`／`discord.md` 成品 → `photos/`），不進題庫。
2. 貼給 Claude 添削。Claude 針對「自然度」回饋，不只是文法對不對：文法正確但日本人不會這樣講的，要指出為什麼不自然，並給 2–3 個替代說法。
3. 有 pattern 價值的錯誤（助詞、語域混用、直譯腔、自他動詞等）記進 `review/mistakes.md`，同類型累加次數，累積到一定量時 Claude 會主動點出我個人的弱點。

除了寫 posts，也可以請 Claude 扮演 30 歲上下的日本朋友，做口說式的輸出練習：1 分鐘あらすじ、ネタバレなし／タメ口／丁寧語三種版本、給情境反推。

兩條線靠「複習」和「用出來」接起來：輸入線累積的表達，要在輸出線的 posts 裡實際用過，才算真的學會。

### 資料怎麼流動

| 檔案                 | 誰寫              | 誰讀                 | 作用                       |
| -------------------- | ----------------- | -------------------- | -------------------------- |
| 各素材資料夾的 `.md` | 我貼、Claude 整理 | 複習時 Claude 讀     | 題庫（粗體表達）           |
| `review/review-log.md` | Claude 複習後追加 | 下次複習挑題時       | 記憶曲線：誰沒考過、誰錯過 |
| `review/mistakes.md`   | Claude 改句後追加 | 點出個人 pattern 時  | 我的弱點清單               |
| `input/patterns.md`    | Claude 講解後整理 | 造句、講故事時回頭查 | 可重複使用的文型與助詞對照 |
| `output/posts/`        | 我寫、Claude 添削 | 不進題庫             | 實戰輸出                   |

實際的 AI 互動規則寫在 [`AGENTS.md`](./AGENTS.md)（唯一規則來源，`CLAUDE.md` 只匯入它）。

## 筆記怎麼記

用 [Obsidian](https://obsidian.md/) 管理。

- **`input/drama/`**：一部劇/節目一個 Markdown 檔（檔名帶年季，如 `2026夏_さよならノワール.md`），同一部作品依集數用二級標題分段（`## ep1`、`## ep11`，小寫、不補零）。
- **`input/anime/`**：一部動畫一個 Markdown 檔，格式同 `input/drama/`。
- **`input/youtube/`**：一個頻道一個 Markdown 檔，一支影片一個二級標題（`## 日期 | 影片標題`）。除了影片裡講的話，也可以記影片標題和觀眾留言（用 `（タイトル）`、`（コメント欄）` 標明來源）；整句粗體的留言是為了學「日本人在想什麼、聊什麼」，複習時考視角和前提。
- **`input/instagram/`**：一個帳號或一個節目一個 Markdown 檔，一則貼文一個二級標題（`## 日期 | 標題`，限時動態用 `## ストーリー`）。SNS 的口語和網路用語很多，要分清楚哪些是日常也能用、哪些只適合 SNS。
- **`input/2idiots/`**：日文課的筆記（上課筆記、老師的貼文、我自己寫的稿），結構自行決定。
- 每則筆記用 `-` 條列一段**完整對話或完整一段話**（不是單獨抄一個詞），場景說明用括號註記。
- 值得學的重點表達用 **粗體** 標起來。

範例（`input/drama/2026夏_さよならノワール.md` 的 `## ep11` 段落）：

```markdown
- 決着をつけたいと言ってたのに**腰砕けですね**
  **いいたい放題だね**
  いいたくなりますよ、逃げる黒木さんをみたくないんで
- 署長から勝手に動くなと改めて厳命された
  **くさいものには蓋をする**ってやつですか
```

保留完整對話而不是單記一個成語，是為了複習時能看出「這句話是在什麼情境下講出來的」。

## 檔案結構

```
.
├── AGENTS.md          # AI 指示檔（唯一規則來源）
├── CLAUDE.md          # 匯入 AGENTS.md（給 Claude Code 用）
├── README.md          # 這份文件
├── emoji.md           # 表情符號複製用的參考連結
├── input/             # 輸入：看 drama／anime 等記下來的素材
│   ├── drama/         # 日劇、綜藝的台詞筆記
│   │   └── <年季>_<作品名>.md   # 例：2026夏_さよならノワール.md
│   ├── anime/         # 動畫的台詞筆記
│   │   └── <作品名>.md
│   ├── youtube/       # YouTube 頻道的筆記
│   │   └── <頻道名>.md
│   ├── instagram/     # Instagram 帳號／節目的貼文筆記
│   │   └── <帳號或節目名>.md
│   ├── 2idiots/       # 日文課的筆記
│   │   └── <檔名>.md
│   └── patterns.md    # 從輸入素材萃取出的文型與助詞講解（不當題庫）
├── output/            # 輸出：我自己寫、發出去的東西
│   ├── posts/         # 我發出去的貼文（企画、文案、照片）
│   │   └── YYYYMMDD_主題/
│   └── slides/        # 預留給之後可能做的簡報（目前是空的）
└── review/            # 複習與回饋：AI 追加的紀錄
    ├── review-log.md  # 複習紀錄
    └── mistakes.md    # 錯誤日誌
```

## 使用方式

1. 在專案根目錄開 Claude Code。
2. 貼上想記的台詞或講法，請它幫忙整理成筆記格式並解釋語感。
3. 想練習時直接說「幫我造句練習」、「來練 1 分鐘あらすじ」或「複習」，AI 會依 `AGENTS.md` 裡的規則出題。
4. 想被改日文時，直接貼上自己寫的內容，AI 會回饋並更新 `review/mistakes.md`。
